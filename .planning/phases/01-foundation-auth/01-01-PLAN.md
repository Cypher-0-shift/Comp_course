  <name>Task 2: Create Supabase schema.sql with all tables, RLS policies, and indexes</name>
  <files>
    supabase/schema.sql
  </files>
  <action>
    Write complete DDL to supabase/schema.sql implementing the schema from CONTEXT.md:
    1. **academic_years** table: id (uuid, pk), start_year (int), end_year (int), is_active (bool, default false), label (generated: start_year || '-' || substr(end_year::text, 3, 2)), created_at, updated_at. Unique constraint on (start_year, end_year). Only one active year at a time (partial unique index).
    2. **departments** table: id (uuid, pk), name (text), code (text, unique), academic_year_id (uuid, fk → academic_years), created_at, updated_at.
    3. **faculty** table: id (uuid, pk), user_id (uuid, unique, fk → auth.users), emp_id (text, unique), name (text), email (text), phone (text), department_id (uuid, fk → departments), academic_year_id (uuid, fk → academic_years), created_at, updated_at.
    4. **subjects** table: id (uuid, pk), code (text), name (text), department_id (uuid, fk → departments), academic_year_id (uuid, fk → academic_years), created_at, updated_at. Unique on (code, academic_year_id).
    5. **faculty_subjects** junction table: id (uuid, pk), faculty_id (uuid, fk → faculty), subject_id (uuid, fk → subjects), unique (faculty_id, subject_id).
    6. **students** table: id (uuid, pk), user_id (uuid, unique, fk → auth.users), register_no (text, unique), name (text), program (text), mobile (text), email (text), department_id (uuid, fk → departments), academic_year_id (uuid, fk → academic_years), created_at, updated_at.
    7. **enrollments** table: id (uuid, pk), student_id (uuid, fk → students), subject_id (uuid, fk → subjects), academic_year_id (uuid, fk → academic_years), status (text, default 'enrolled', check: enrolled/completed/dropped), created_at, updated_at. Unique on (student_id, subject_id, academic_year_id).
    8. **Indexes**: FK columns, academic_year_id on all tables, user_id on faculty/students.
    9. **updated_at trigger**: Function update_updated_at_column() + triggers on all tables.
    10. **RLS Policies** (per CONTEXT.md decisions):
       - academic_years: SELECT for authenticated users
       - departments: SELECT for authenticated users
       - subjects: SELECT for authenticated users
       - faculty: SELECT for authenticated users (reference data)
       - faculty_subjects:
         - Faculty: SELECT WHERE faculty.user_id = auth.uid() (via join)
         - HOD: SELECT WHERE department_id = app_metadata.department_id
         - Dean: SELECT all
       - students:
         - Student: SELECT WHERE user_id = auth.uid()
         - Faculty: SELECT via enrollments → subjects → faculty_subjects WHERE faculty.user_id = auth.uid()
         - HOD: SELECT WHERE department_id = app_metadata.department_id
         - Dean: SELECT all
       - enrollments:
         - Student: SELECT WHERE student.user_id = auth.uid()
         - Faculty: SELECT via subject → faculty_subjects WHERE faculty.user_id = auth.uid()
         - HOD: SELECT WHERE subject.department_id = app_metadata.department_id
         - Dean: SELECT all
    11. **Enable RLS**: ALTER TABLE ... ENABLE ROW LEVEL SECURITY on all 7 tables.
    12. **Comments**: Document each policy purpose.
