  Key Decisions (from CONTEXT.md)

  - Admin creation: SQL seed script, roles in app_metadata (hod/dean with department_id)
  - Folder structure: Feature-based (features/auth, student-portal, faculty-dashboard, admin-portal)
  - Supabase: Email confirm required, app_metadata for roles, PKCE, defaults for JWT/session
  - Academic year: Separate academic_years table + FK on all relevant tables
  - RLS: faculty_subjects junction table; student=own, faculty=assigned courses, HOD=dept, Dean=all
  - Session: 30-min idle timeout, max 3 concurrent sessions, cross-tab sync, useAuth() hook
  - Errors: Auth error boundary, Sonner toasts, TanStack Query, 401→login, 403→access-denied
  - Routing: React Router v6, ProtectedRole wrapper, role hierarchy (Dean≥HOD>Faculty>Student)
